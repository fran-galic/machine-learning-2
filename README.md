# Machine Learning 2

Laboratory assignments and homework for the **Machine Learning 2 (Strojno učenje 2)** course at the **Faculty of Electrical Engineering and Computing (FER), University of Zagreb**.

**Academic Year:** 2026/2027

## Course Overview

This course explores the theoretical foundations of machine learning, with a particular focus on **Statistical Learning Theory**, generalization, and the mathematical principles underlying learning algorithms.

It covers fundamental concepts such as PAC learning, generalization bounds, and model complexity, and examines how these theoretical tools apply to classical machine learning algorithms and modern deep learning architectures.

### Key Topics

- **Statistical Learning Theory:** PAC learning, generalization bounds, and sample complexity
- **Learning Theory Foundations:** Empirical Risk Minimization (ERM), bias-variance tradeoff, and VC dimension
- **Regularization and Optimization:** L1/L2 regularization, gradient descent, and stochastic optimization
- **Kernel Methods:** Reproducing Kernel Hilbert Spaces (RKHS) and kernel-based learning
- **Ensemble Learning:** Boosting, AdaBoost, and Random Forests
- **Complexity Measures:** Rademacher complexity and generalization analysis
- **Advanced Learning Theory:** PAC-Bayes theory, compression bounds, and Minimum Description Length (MDL)
- **Deep Learning Theory:** Training dynamics, implicit regularization, and generalization in neural networks
